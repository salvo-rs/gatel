# 来源快照编码：检查点输入基础

`gatel_model::snapshot_codec` 是无 I/O 的有界二进制编解码器，不新增模型层依赖。
用于保存 lowered Snapshot；不是完整检查点、原始文件备份或生产恢复承诺。
格式仍为实验接口，版本不兼容时明确拒绝，不猜测旧版本。

## 格式与保真

- 头部为 8 字节 `GATELS01` 和 32 字节正文校验值。校验使用 Hasher 域
  `gatel.snapshot.codec.v1`；不是 MAC、签名或加密。
- 固定宽度整数采用 little-endian，计数/字符串 UTF-8 字节长度为 u32，来源修订为 u64。
  源内容指纹保存原始 32 字节，不重新计算或认证其与配置树的关系。
- 来源按 SourceId 顺序编码；重复或无序来源在解码时拒绝，不能静默覆盖。File/Admin/Kubernetes
  身份独立；Admin 名称必须为模型规范名称。空来源保留，不当作不存在。
- Node 的名称、顺序化 args/props/children 和每个 Origin 完整保存。重复属性仍保留原顺序，
  是否允许重复由后续规范化/指令解码决定。不会借序列化静默修正输入语义。
- Scalar 分别编码 null、false、true、i64、f64 位模式和字符串。保留负零、无穷和 NaN 载荷；
  浮点数不经过十进制或 JSON 转换。是否允许特定浮点值仍由业务验证决定。
- Origin 分别保存文件名+span、API source+pointer 或 synthetic reason，以及 field path。
  span offset/length 使用 u64，解码时检查目标平台 usize 是否可表示；line/column 为 u32。

## 边界与失败语义

总编码长度上限 16 MiB（含 40 字节头部）；单字符串不超过 1 MiB；最多 256 个来源、
65,536 个节点、262,144 个值（参数与属性值合计），树深不超过 64。空树不消耗节点深度。
编码和解码同时执行限制，不从未验证计数预分配集合；字符串在验证字节存在和 UTF-8 后分配。
解码先限制输入长度并验证校验值，再构建树；宿主读盘时仍须先做有界读取。

损坏、截断、尾随数据、非法 tag/UTF-8、重复来源、超限均返回错误，不返回部分 Snapshot。
错误消息不包含配置原文。返回的树和字节可能包含秘密，调用者必须实施私有目录/权限策略，
不能用普通 Debug/日志打印。长度和计数限制不是整个进程的 RSS 上限，也没有安全擦除保证。

## 已验证及未完成

单测覆盖所有标量位模式、三类来源/Origin、多来源空贡献、每个截断位置和单字节改写、
正确校验下的结构错误、深度/计数/字符串/总长度限制。规划层测试把已发布来源编码、解码后
在独立新 BootId 的 GenerationStore 重新编译，得到相同 plan hash。
模糊测试 `snapshot_codec` 同时输入任意帧和重新计算校验值的任意正文，成功解码时断言
重新编码字节完全相同；它不验证文件落盘、实例绑定或外部资源恢复。

宿主已提供独立的[检查点封装](checkpoint-envelope.md)，包含实例、注册表、计划与日志前缀关联；
内部磁盘层已提供临时文件写入/同步/替换；仍须实现全来源原子取样、生产启动前验证及恢复。
反序列化的来源身份、修订和指纹不构成
写权限，不能绕过 GenerationStore 的来源准入与正常编译。当前没有生产检查点读写入口。
